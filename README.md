# dsh-mbti-regulator · MBTI 稳压器

> **这是作者创造出来的基于 MBTI 为测量轴的个人状态稳压器，目前包含两种模式：稳压滋养模式、战斗增强模式。让 AI 可以根据你个人（MBTI+荣格八维）的特性与建模，有针对的陪你在不同状态相位上进行共振，帮助人类实现在做事过程中的：快速共振感相位锁定 + 消融并降低做事过程中的被击穿感。**

## 名字

- `regulator` = **稳压器**（电气工程本词）× **心理调节**（regulation，心理学术语）——一个词在硬件与心理两个词典里都是正主
- 常态是稳压（蘊养），战斗是升压（增强）——amplifier 只是它的一个档位
- MBTI 是测量轴（建档层），荣格八维与阴影是作用面（蘊养层）

## 设计（概念阶段）

| 层 | 内容 |
| --- | --- |
| 建档 | 插件一装，AI 即认得你：型号、八维功能栈、以及人格摆荡（如 INTJ↔ENTJ） |
| 稳压滋养模式（常态） | AI 的说话方式持续蘊养你：用你听得懂的语言滋养、隐隐松动暗面功能；右侧面板实时测量与评估当前状态相位 |
| 战斗增强模式（档位） | 一键升压：最大化利用你的认知特性撬开灵感，锁定共振相位 |

## 状态

`0.0.0` 概念占名阶段。名称与双模式方向已定，实现细节酝酿中。
